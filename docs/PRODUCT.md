# 📅 MeetMe - Documento de Produto

## Visão Geral
MeetMe é um sistema de agendamento de reuniões pessoal, estilo Calendly, 
onde profissionais (especialmente devs em busca de emprego) compartilham 
um link único para que recrutadores e outras pessoas agendem reuniões 
diretamente no seu calendário.

## Problema que Resolve
- Coordenar horários por email/WhatsApp é lento e frustrante
- Recrutadores precisam de uma forma rápida de marcar entrevistas
- Ferramentas existentes (Calendly) são caras para features básicas
- Falta personalização e controle total sobre a experiência

## Solução
Um app simples, bonito e configurável onde:
1. O host configura seus horários e tipos de reunião
2. Conecta seu Google Calendar (opcional)
3. Compartilha um link (ex: meetme.dev/schedule/marcelino)
4. Guests escolhem horário disponível e agendam
5. Todos recebem confirmação por email
6. Evento é criado automaticamente no Google Calendar

## Público-Alvo
- **Primário:** Desenvolvedores em busca de emprego (entrevistas)
- **Secundário:** Freelancers, consultores, coaches
- **Terciário:** Qualquer profissional que recebe muitas reuniões

## Diferenciais
- Gratuito para uso básico
- UI moderna e personalizável
- Foco em recrutamento (templates de entrevista)
- Simplicidade: sem features desnecessárias
- Open source / self-hostable

## Métricas de Sucesso
- Tempo para agendar < 60 segundos
- Zero conflitos de horário
- 100% de confirmação por email
- Link compartilhável em 1 clique
