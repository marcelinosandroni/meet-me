# 🛠️ Skills — Comandos e Scripts Prontos

> Pasta de referência com comandos, scripts e receitas prontas pra você copiar e colar no terminal.
> **Não é código do app** — é toolkit de desenvolvimento.

---

## 📋 Skills Disponíveis

| Skill | Arquivo | O que faz |
|-------|---------|-----------|
| 🔧 Git — Reescrever Commits | [`git-rewrite-commits.md`](./git-rewrite-commits.md) | Configura autor, reescreve histórico, força push |

---

## 🚀 Como usar

1. Abra o arquivo da skill que você precisa
2. Copie o bloco de comando
3. Cole no terminal dentro do projeto
4. Ajuste os valores (nome, email, etc) pro seu caso

## 💡 Quer adicionar mais skills?

Crie um novo arquivo `.md` aqui com:
- Nome descritivo
- Comandos prontos pra copiar
- Explicação do quando usar
- Exemplos de output esperado

Exemplos de skills futuras:
- `deploy-vercel.md` — Deploy automatizado
- `google-calendar-setup.md` — Configurar OAuth2
- `supabase-migration.md` — Migrations do banco
- `debug-common-errors.md` — Erros frequentes e soluções
